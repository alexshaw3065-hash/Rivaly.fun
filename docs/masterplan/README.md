## How to use these docs

- Before proposing or building a feature, run it through the **Rivaly Test** in [04-design-principles.md](04-design-principles.md#68-the-rivaly-test).
- Before deciding *whether* a feature belongs in the current build, check [08-v1-scope.md](08-v1-scope.md) — most things wait.
- [07-product-blueprint.md](07-product-blueprint.md) is the full long-term surface area, not a build checklist for now.
